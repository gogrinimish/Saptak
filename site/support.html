Saptak support

A little help
with your audio.

Saptak plays audio directly from folders you choose. It does not import your files or require a Saptak account.

Choose a folder

Tap Choose folder and select a folder containing audio. On iPhone or iPad, cloud locations appear through Apple's Files app when the provider supports folder access. On Mac, use a local folder or an available Finder location. Every subfolder becomes a playlist; Play all includes its descendants.

Missing or unavailable tracks

Use Refresh after adding, moving or removing files. If a cloud file is unavailable, check your connection and open it in Files or Finder first. Providers may need to download a file before playback. Saptak cannot play formats unsupported by the device.

Playback and AirPlay

Check the selected audio output and volume. On iPhone or iPad, use AirPlay in the expanded player; on Mac, choose the output through Control Center or Sound settings. If a receiver also fails with another audio app, check the receiver and network connection.

Remove saved settings on Mac

Quit Saptak. In Finder, choose Go > Go to Folder and enter ~/Library/Containers/com.playsaptak.app. Moving this app container to Trash removes its saved folder access and playback state. Your original audio outside that container stays in place. Relaunch Saptak to choose a folder again.

Report a problem

Open a GitHub issue with your device, operating-system version, Saptak version and steps to reproduce the problem. GitHub issues are public and require a GitHub account. Never attach personal recordings, private file paths or account credentials. Use a fictional example instead.

Privacy and source

Read the privacy policy and browse the MIT-licensed source. Saptak does not collect listening history or operate an account service.
