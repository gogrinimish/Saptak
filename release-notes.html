Version 0.2.0 · Upcoming

Your audio.
More within reach.

Version 0.2.0 is prepared for App Store review. Version 0.1.0 is available now on the App Store. These features arrive with 0.2.0 after approval and release.

Your folders in CarPlay

Choose your audio folder on iPhone while parked, then browse it through a compatible CarPlay system. Start a folder playlist, choose a track or open Up Next. Native Now Playing supplies playback controls. On iOS 26 and later, compact folder tiles show more of the hierarchy without needing artwork; earlier versions use lists. Contents appear before playback shortcuts.

Find the original

Use Show in Files on iPhone or iPad, or Show in Finder on Mac. When a Files provider cannot reveal the file directly, Saptak offers the filename and a folder browser fallback. Sharing remains explicit and leaves your original in place.

A little more room on Mac

The smaller player places controls below the track title and seek bar. Original-file actions live in its three-dot menu, keeping the library in view.

Feedback without a GitHub account

Use the speech-bubble button in the iOS library toolbar or Mac sidebar. Preview your message, then open an email draft or copy it. App and device details are optional and off for each new report. Nothing is sent automatically.

A clearer interface

Sharing, feedback, cloud help, the font license and Up Next share a themed layout with a clear Done button.

Still yours

No accounts, analytics, subscriptions or permanent imports. Your existing folder selection and local recovery state are retained. Cloud availability depends on the provider and downloads can use storage. CarPlay requires compatible hardware.
